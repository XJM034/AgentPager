# Triage Labels

| Matt Pocock Skills 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |

| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent |
